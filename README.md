# Cofre do Gui

App pessoal de controle de dinheiro. Abre em tela cheia no iPhone e funciona sem internet.

Os dados ficam só no aparelho (nada é enviado pra cá). Pra não perder nada, use ⚙️ → Geral → Exportar dados de vez em quando.

## Placar (pasta `placar/`)

Placar SIM vs NÃO. Abre em tela cheia no iPhone e funciona sem internet. Pontos, cores e foto de fundo ficam só no aparelho.
